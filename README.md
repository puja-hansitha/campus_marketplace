# Campus Marketplace

A college marketplace website where students can buy and sell products within their campus community.

## Features

- 🔐 User Authentication (Login/Register)
- 📦 Sell Products (Upload photo, description, category, price)
- 🛒 Buy Products (Search, filter by category)
- 💬 Messaging System (Chat with buyers/sellers)
- 📋 Requests Management (Sellers manage buyer interest)
- 📊 History Tracking (Selling, Sold, Bought items)
- 👤 Profile Management (Edit name, profile photo)
- 🔔 Notifications System

## Tech Stack

- React + TypeScript
- Vite
- Firebase (Auth, Firestore, Storage)
- CSS3 with modern gradients and animations

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   cd client
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
